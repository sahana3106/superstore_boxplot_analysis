# Superstore Profit Analysis using Boxplots

## Project Overview
This project focuses on analyzing profit distribution, variability, spread, and outliers in the Superstore dataset using statistical concepts and data visualization techniques.

The analysis explores how sales, discounts, and profit vary across different product categories and how boxplots help identify outliers and business trends.

---

## Dataset
The dataset contains Superstore sales information including:
- Sales
- Profit
- Discount
- Product Categories
- Customer and Order Details

---

- Pandas

- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### Statistical Analysis
- Standard Deviation

### Visualization
Created visualizations using:
- Boxplots
- Scatter plots
- Distribution analysis

### Key Focus Areas
- Profit variability across categories
- Outlier detection using boxplots
- Relationship between sales, discount, and profit
- Business interpretation of statistical measures

## Key Insights

### Technology Category
- High average profit observed
- High variability indicates greater fluctuation and risk

### Outlier Detection
- Boxplots helped identify extreme profit and sales values
- Outliers highlighted unusual business behavior and product performance

### Correlation Analysis
- Explored relationships between sales, discounts, and profit
